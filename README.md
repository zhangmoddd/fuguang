# 浮光

> 轻量 Windows 桌面悬浮工具箱 —— 一个 1.5 MB 的安装包，解决电脑上那些反复做的琐事。
> 全局热键 `Ctrl+Shift+Space` 随时唤出，不占任务栏。

浮光常驻在屏幕边缘，是一个可以拖动、可以吸附的小球。
左键点开主面板，右键弹出快捷菜单。所有功能都收在这个面板里，不用去任务栏找图标。
**小球的位置会被记住**，拖到顺手的地方之后，下次开机还在那儿。

**可以同时开好几个面板窗口** —— 一个停在「工作」文件夹、一个停在「临时」，
并排放在屏幕上各看各的，不用来回切。右键点小球 →「新建窗口」。

**设计取向：小、快、不打扰。** 不做内嵌窗口、不做后台常驻服务、不写注册表。
整个软件就是一个 exe 加一个数据文件夹。

## 能做什么

五个页签：**笔记 / 计时 / 备忘 / 链接 / 设置**。按 `Ctrl+K` 跨全部四类数据搜索，
**回车直接跳过去并打开它**。

| 页签 | 做什么 |
|---|---|
| **笔记** | 天天要重复敲的账号、地址、格式模板存进来，**点一下直接粘到你刚才光标的位置**（不是在浮光自己身上）。**能塞图片**：点「加图片」选文件、把图直接拖进来、或者截图后按 `Ctrl+V` —— **前两条一定可用**，`Ctrl+V` 取决于系统（见「已知限制」），带缩略图和大图预览。另有标签、备注、文件夹分类、收藏置顶；标记为敏感的条目在列表里显示成圆点，防录屏、防旁人扫一眼。**边写边存**，没有「保存」按钮，切页签或直接退出都不会丢 |
| **计时器** | 倒计时 / 番茄钟 / 秒表 / 闹钟。倒计时**存的是绝对结束时刻**：设个 30 分钟然后关机，一小时后开机，它告诉你"已完成"，而不是从 30 分钟重新开始。闹钟设的是"几点"而不是"多久之后"，可以勾每天重复；响铃按手机闹钟的逻辑 —— **响到你处理为止**，带「稍后 5 分钟」 |
| **备忘** | 按日期归集的日记式，**同样能塞图片**。**「记录日期」和「提醒时间」是两个独立字段** —— 今天可以写一条"下周交材料"，它留在今天这一页（将来回顾时你知道这事是什么时候想起来的），到那天才提醒你。提醒支持每天 / 每周 / 每月 / 工作日；错过的提醒开机后**汇总补发一条**，而不是噼里啪啦弹八个窗 |
| **快捷链接** | 程序 / 文件夹 / 文档 / 网址集中到一处，点一下就打开。**自动从 exe 里抠出真实图标**，也支持把文件直接拖进面板，一次能框选一批。**目标被挪走或删掉时会提前标出来**（图标压暗 + 标清是哪种失效），点它开的是「修好它」面板而不是一句报错：里面有原因、有「重新定位…」、还有**在原来那个文件夹附近自动找到的同名文件**，点一下就改回去。菜单里也有「以管理员身份运行」 |
| **设置** | 全局热键、开机自启、提示音、界面字号四档、悬浮球配色七套、数据导出与恢复 |

**右键菜单**：条目、图片、编辑器里选中的文字都支持右键 ——
「键入到当前光标」「复制」「编辑」「删除」「移动到…」「另存为」「查看大图」这些动作都在里面。

**三个刻意的取舍：**

- **纯启动器，绝不把外部程序窗口嵌进面板** —— 那是臃肿和一堆兼容问题的来源。
- **数据不加密，就是几个纯文本 JSON。** 好处是你能直接用记事本打开检查、手动改、
  拷走备份；代价是敏感内容只有"列表遮罩"这一层视觉保护。
  这是刻意的：加密意味着你一旦忘记密码，数据就永久找不回来了。
  请自行评估要不要把真正重要的密码放进来。
- **不抢任务栏、不写注册表、不做常驻服务。** 卸载就是删掉一个文件夹。

## 下载安装

到 [Releases](https://github.com/zhangmoddd/fuguang/releases) 下载 `fuguang_x.x.x_x64-setup.exe`，双击安装。
（文件名是英文的：GitHub 的 Release **不允许资产名带中文**，会被静默剥成 `_x.x.x_...`。
装完之后程序名、开始菜单和界面都是「浮光」。）
安装完从开始菜单启动，屏幕右侧会出现一个蓝色小球。

不需要装 Node.js、不需要 Rust、不需要 WebView2 运行库（Windows 10/11 自带）。

<details>
<summary><b>从源码运行 / 自己编译</b></summary>

需要 **Node.js 22.12+** 和 **Rust 1.77.2+**（这两个下限是依赖树实际要求的，不是拍脑袋写的）。

```bash
git clone https://github.com/zhangmoddd/fuguang
cd fuguang
npm install
npm run desktop:dev
```

Windows 用户可以直接双击仓库里的 `1-开发模式.bat`：跑的是真窗口真程序，
但前端改动存盘即生效，只有 Rust 代码改了才需要增量编译。
`2-重新编译.bat` 出正式版，产物在 `src-tauri/target/release/fuguang.exe`。

> ⚠️ **别用 `cargo build` 去看前端改动。** 它**不跟踪 `dist/` 的变化** ——
> 你改完前端、跑 `cargo build`、启动 exe，看到的会是**上一次构建时嵌进去的旧界面**，
> 很容易误判成"我的改动没生效"。要跑最新界面请用 `npm run desktop:dev`，
> 或者 `npm run desktop:build`（它配了 `beforeBuildCommand: npm run build`，
> 会先重建 `dist/`）。

> 这 4 个 `.bat` 的界面文字是英文，而且刻意写成「纯 ASCII + CRLF 换行」。
> **用编辑器改它们时请务必保持 CRLF 且不要引入非 ASCII 字符**，
> 否则双击会毫无反应（实测踩过）。

</details>

## 操作方式

| 操作 | 效果 |
|---|---|
| **按 `Ctrl+Shift+Space`** | **展开 / 收起主面板**（设置页可改，全局生效） |
| **面板里按 `Ctrl+K`** | **全局搜索（跨四个页签）**，按键见下表 |
| 点标题栏的放大镜 | 同上（打开全局搜索）。它比旁边几个按钮大一圈、带淡蓝底 |
| 点标题栏的窗口图标 | **再开一个面板窗口** —— 两个窗口能并排，各自停在不同页签 / 文件夹 |
| 左键点小球 | 展开 / 收起主面板 |
| 右键点小球 | 快捷菜单（打开面板、**新建窗口**、数据文件夹、隐藏小球、退出） |
| 按住小球拖动 | 移动位置 |
| 面板里按 `Esc` | 收起面板。**有任何浮层开着时（右键菜单、大图预览、命令面板、日历、文件夹弹层…），只关最上面那一层** —— 不会连带把编辑器或整个面板也关掉 |
| 点面板右上角的 `✕` | 收起面板。**第 2 个及以后的面板窗口是「关掉」而不是「收起」** —— 见下面的说明 |
| 面板里按 `1`~`9` | 快速切换页签 |
| 面板里按 `Ctrl` + 滚轮 | 缩放当前页签的图标 / 列表密度（各页签独立记忆） |
| 左键 / 右键点托盘图标 | 展开收起主面板 / 完整菜单（含**新建窗口**与退出） |

> **为什么第 2 个面板的 `✕`（和 `Esc`）是「关掉」而不是「收起」**：
> 第一个面板是常驻入口，收起来还能从悬浮球和托盘唤回；
> 而**多出来的窗口藏起来就找不回来了** —— 悬浮球和托盘只会唤回第一个面板，
> 而藏起来的那个仍占着窗口编号，于是它看不见、回不来、还一直占着内存。
> 关掉反而是**可恢复**的：再点一次「新建窗口」会拿回同一个编号，
> 连带它上次停的页签和文件夹。
> 关之前会先把没落盘的改动写下去；**写不下去时会问你一句，而不是直接丢掉**。

**搜索面板里的按键：**

| 键 | 做什么 |
|---|---|
| `Enter` | **跳到它所在的位置**（进对应文件夹 / 切到那一天）**并打开它**。链接是跳过去并选中那一格，**不会启动它**（启动走 `Ctrl+Enter`） |
| `Ctrl+Enter` | 执行这个条目的主动作：笔记 → 键入到当前光标；链接 → 在外部打开；备忘 / 计时器 → 打开编辑器 |
| `Shift+Enter` | 复制（笔记 → 复制正文；链接 → 复制地址） |
| `↑` `↓` / `Esc` | 选择 / 关闭 |

## 数据存在哪

```
%APPDATA%\浮光\
├── snippets.json     笔记
├── timers.json       计时器
├── memos.json        备忘
├── links.json        快捷链接
├── folders.json      文件夹（链接 / 笔记 / 计时器共用）
├── media\            塞进笔记 / 备忘的图片本体
├── window.json       悬浮球和各个面板窗口的位置
├── settings.json     设置
└── app.log           诊断日志（超 256 KB 自动清空）
```

**每个集合一个文件**，而不是全部塞进一个大 JSON：写坏一个不会连累其他，
你也能单独备份或删掉某一类数据。文件损坏时浮光会自动把它备份成
`xxx.corrupt-<时间戳>.json` 再以空数据启动，不会让你连软件都打不开。

**图片单独放在 `media\` 目录里，不塞进 JSON。** 数据文件是整份重写的，
图片进去会让它膨胀几个数量级，还会污染搜索和摘要。
导出备份时图片会一起打包进去，所以**带图片之后备份文件会比以前大不少**。

想快速找到这个文件夹：右键点小球 → 打开数据文件夹。
设置页 →「数据」里还有**导出 / 恢复**按钮，把全部数据打成一个 JSON 文件。

**为什么放 `%APPDATA%` 而不是 exe 旁边**：你要把 exe 发给别人用，
而别人可能把它放在 `C:\Program Files\` 这种只读目录里，放旁边会直接写入失败。

> **软件"自己退出了"时先看 `app.log`。** 正式版没有控制台，崩溃默认不留任何痕迹，
> 所以那里刻意记了三类行：`启动完成`、`退出：来自哪里`、`panic @ 文件:行号`。
> 日志最后一行是"启动完成"、后面什么都没有 → 进程是被崩溃或强杀带走的。

## 已知限制

- **面板打开时会取得焦点**，那期间你原来程序里的光标会看不见（焦点回到目标程序时
  又出现，文字插入位置不受影响）。要做到「不抢焦点、光标全程不消失」需要专门的
  交互设计（`WS_EX_NOACTIVATE` 和「按钮点击可靠」在 Windows 上存在冲突）。
- **到点弹出的提醒窗也会取得焦点。**
- **数据不加密**，`%APPDATA%\浮光\` 下是明文 JSON，只有列表遮罩这一层视觉保护。
- **小球第一次出现的位置按主显示器算。** 之后你拖动的位置会被记住；多显示器下按
  「那块屏幕还在不在」决定摆哪儿 —— 副屏拔掉或改了排列时会退回默认位置。
  面板窗口同理：按你放它的那个点所在的显示器。
  （跨屏 + 不同缩放率下的实际表现**需要你实测**，我没有可用的多屏环境。）
- **图片用键盘粘贴（`Ctrl+V`）在某些系统上可能不生效。** 图片的几条路里，
  「加图片」按钮、**「剪贴板」按钮**和「把图拖进来」**一定可用**；
  `Ctrl+V` 走的是网页层的剪贴板接口，能不能拿到图片取决于 WebView2 与系统的组合 ——
  **这一条我无法在无界面环境里验证**。如果你按 `Ctrl+V` 没反应，请改用那两个按钮。
  （纯文字的 `Ctrl+V` 不受影响，照常可用。）
- **全局热键只唤出第一个面板。** 想开更多窗口请用小球或托盘右键菜单里的「新建窗口」——
  给每个窗口绑一个独立热键要改整套热键注册模型，暂时不做。
- **链接的「失效」标记是纯本地核对的结果，网络位置不核对。** UNC 路径
  （`\\服务器\共享\…`）和映射的网络盘刻意跳过：核对是打开链接页时**自动**跑的，
  而链接目标可以是别人给的备份文件里带进来的任意字符串，去连一台陌生主机会把
  当前用户的 NTLM 响应发出去。代价是网络盘断开时格子上不会出现失效标记，
  只会在点开时报错。
- **「附近找到的同名文件」只往原来那个文件夹下面找三层**，不跟 junction / 符号链接，
  跳过隐藏 / 系统目录，最多花 1.5 秒、最多看 4000 个目录项、最多列 8 个候选。
  **改过名**或**换到别的盘/别的目录树**的文件找不到 —— 那种情况用「重新定位…」自己挑。
  候选里显示大小和修改时间，**点之前请对一下**：同名不等于同一个东西。
- **快捷方式（`.lnk`）只能解析出带本地路径的那一类**（本机 51 个桌面快捷方式里 48 个）。
  Store 应用那种没有本地路径的读不出来，这时只按「快捷方式文件本身在不在」处理，
  不会乱报失效；界面退回通用的原因提示。
- 卸载**不会删除数据**；想彻底清理请手动删掉 `%APPDATA%\浮光`。
